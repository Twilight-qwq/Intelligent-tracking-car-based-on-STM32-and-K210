# 图片目录

存放文档里引用的图片：波形图、串口截图、示意图。

---

## 一、命名规则

```
T编号_内容.png        例如  T07_速度环阶跃.png
示例_内容.png          例如  示例_速度环响应对比.png   （示意图，不是实测）
```

| 前缀 | 含义 |
|---|---|
| `T07_` | 第 7 次试验的实测图，和 `调参记录.md` 里的 `### T07` 对应 |
| `示例_` | 讲解用的示意图，**不是**实测数据 |

---

## 二、怎么在文档里引用

在 `Doc/` 下的 Markdown 文件里，用**相对 `Doc/` 的路径**：

```markdown
![T07 速度环阶跃](图片/T07_速度环阶跃.png)
```

> ⚠️ 写 `图片/xxx.png`，**不要**写 `Doc/图片/xxx.png`。
> 因为引用是相对于当前这个 md 文件所在的目录（也就是 `Doc/`）。

---

## 三、怎么截图

| 方法 | 操作 |
|---|---|
| Windows 自带 | `Win + Shift + S` → 框选 → 自动进剪贴板 → 粘贴到画图里另存为 PNG |
| 微信/QQ | `Alt + A` 截图后保存 |

**截完最好裁一下**，去掉窗口边框和多余空白，能省不少体积。

---

## 四、注意事项

| # | 注意 | 为什么 |
|---|---|---|
| 1 | 图片必须一起提交到 git | 只提交 md，换台电脑或推到远程图片就显示不出来 |
| 2 | 单张尽量控制在 300 KB 以内 | git 里存的是历史版本，图太大会越滚越大 |
| 3 | 截图里不要带无关窗口 | 报告和答辩时不好看 |
| 4 | 文件名用中文没问题 | 但要和记录编号对上，别叫 `新建图片1.png` |
