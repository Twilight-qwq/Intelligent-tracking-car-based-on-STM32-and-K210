### 2.1 起转点要提前，不能等走到拐点

转弯时车走的是圆弧，半径 `R = 速度 ÷ 角速度 = 42.1 ÷ 4.2 = 10.0 厘米`。

**在拐点上才开始转，车会切进内线 10 厘米**（仿真实测，见 §10）。
要让圆弧正好和两条边相切，必须在拐点**之前** `R × tan(θ/2)` 就开始转。

| 弯 | 转多少 | 提前多少（R×tan(θ/2)） |
|---|---|---|
| 直角 | 90° | 10.0 cm |
| 钝角 | 39° | 3.5 cm |
| 锐角 | 103° | 12.6 cm |

### 2.2 最终的表

| 相位 | 该走多远（到**起转点**） | 真拐点距离 | 到哪个弯 | 转多少 |
|---|---|---|---|---|
| 0 | **147 cm** | 147 | 直角 | 90° |
| 1 | **106.5 cm** | 110 | 钝角 | 39° |
| 2 | **187.4 cm** | 200 | 锐角 | 103° |
| 3 | **196.5 cm** | 200 | 钝角 | 39° |
| 4 | **100.0 cm** | 110 | 直角 | 90° |
| （回起终点） | 147 cm | 147 | — | 不转 |

**一圈 = 147 + 110 + 200 + 200 + 110 + 147 = 914 cm**（按用户实测的白色路面长度）。

> 表里的 147 / 110 / 200 是**用户实测**；106.5 / 187.4 / 196.5 / 100.0 是减去切点偏移后算的。
> **全部以现场校准为准**，上车后按实际起转位置微调。三个角度依然必须现场量（§7.2）。

## 4. 主循环（每 5 毫秒跑一次）

```
① 读左右轮编码器 → 得到两步走的计数

② 如果是「巡线」或「等里程」状态：
      走过的厘米 =（左计数 + 右计数）÷ 2 × CmPerCount
      Odo = Odo + 走过的厘米

③ 如果 Odo ≥ SegCm[Phase]：
      状态 = 转弯
      转角累计 = 0           ← 清零，开始数转弯的差速

④ 如果是「转弯」状态：
      左右轮按固定差速转：左 = 基速 + 差速，右 = 基速 − 差速
      转角累计 = 转角累计 +（左计数 − 右计数）

      如果 转角累计 ≥ TurnCnt[Phase]：      ← 转够了
          左右轮立刻恢复直行速度            ← 不能等下一帧视觉，会多转
          状态 = 恢复
          恢复计时 = 0
     否则如果 转弯超时（800 毫秒）：          ← 兜底，卡住了
          同上，强制结束

⑤ 如果是「恢复」状态：
      直行，最多 500 毫秒（让相机从弯道画面里缓过来）
      恢复计时到了 → 状态 = 巡线
      Phase = Phase + 1，如果 > 4 则回到 0     ← 换下一段
      Odo = 0

⑥ 如果是「巡线」状态：
      差速 = Kp × 偏差 + Kd × 偏差变化量
      左右轮 = 基速 ± 差速
```

**关键点：转弯的「停」由编码器说了算，不等视觉。** 视觉只在第 ⑥ 步参与。

## 5. 视觉怎么用（四条规则，双方已谈定）

| 情形 | 处理 |
|---|---|
| 里程还没到阈值，视觉报弯（差 > 30 cm） | **不转**。多半是反光。`Suspect = Suspect + 1` |
| 里程还没到阈值，视觉连续 3 帧报弯，且图案像真弯（最近 3 行全丢 + 只剩一条线），差 10~30 cm | **把 Odo 前移一半**（不是清零），然后继续等里程 |
| 里程到了阈值，视觉报不报 | **照转**，不看视觉 |
| 视觉长期不报弯 | **照转**，完全不等视觉 |

**核心原则：里程是硬信号，视觉是软信号。视觉只能用来「发现漂移」，不能改写里程基准。**

## 6. 错位怎么发现（这套方案唯一的自愈手段）

纯里程最大的风险不是精度，是**一旦错位自己不知道，后面全错**。所以必须有检测。

### 6.1 检测一：视觉报警计数

```
如果 Suspect ≥ 3（连续三个弯都出现「视觉先报、里程还差很远」）：
    说明里程系统性偏小（或者视觉系统性误报）
    动作：把 CmPerCount 上调 10%，Suspect 清零，并记一条日志
```

### 6.2 检测二：一圈对账

```
一个相位表走完（Phase 回到 0）时：
    这一圈总里程应该 ≈ 914 cm
    如果总里程 与 914 差超过 15%：
        说明里程刻度有问题，或者漏了一段
        动作：记日志 + 指示灯报警，但不停车
```

### 6.3 检测三（保底）：完全失联就退回老逻辑

```
如果连续两个相位都没被触发（里程一直不动，比如轮子打滑空转）：
    退回到「视觉报弯 → 转 90°」的老逻辑
    并且亮指示灯
```

**这条很重要**：新方案坏了也要能跑，不能比现在更差。

### 7.2 量三个弯的真实转角（30 分钟）

**方法**（每个弯做一次）：

1. 车贴着弯前的直道摆正
2. 地上沿车头方向画一条粉笔线（延长线）
3. 让车按差速转，转到车头大约对准出弯方向
4. **在车头位置点一个粉笔点**
5. 把车拿开，量「起点 → 粉笔点」的连线和原延长线之间的夹角
6. 这个角就是实际转角

**同时记下**：转过这个角，编码器累计了多少计数 → 这就是 `TurnCnt` 的标定值。

## 10. 上不上？判断标准

**先做仿真验证，再上车。**

### 10.1 已经跑完的仿真（`_teach_vision/_mileage_sim.py`）

出弯后车偏离车道中心多少（半车道 = 20 cm，超过就是压线）：

| 情形 | 最大横向偏差 | 结论 |
|---|---|---|
| 表填对（提前 R×tan(θ/2)） | **0.5 cm** | ✅ 几乎完美 |
| 表里填了带尺的 147 | **32.5 cm** | ❌ 直接出赛道 |
| 起转点不提前（就在拐点上转） | 12.3 cm | ⚠️ 切内线 |
| 刻度偏 +5% | 9.1 cm | ✅ 可接受 |
| 刻度偏 +10% | 17.0 cm | ⚠️ 勉强 |
| 刻度偏 +15% | 24.2 cm | ❌ 出赛道 |
| 刻度偏 −10% | 19.9 cm | ⚠️ 擦边 |

**两条硬结论：**

1. **起转点必须提前 `R×tan(θ/2)`**，否则每过一个 90° 弯切 10 cm。
2. **里程刻度必须准到 ±10% 以内**，最好 ±5%。这就是为什么 §7.1 的校准不能省。

### 10.2 还没验的

- 视觉误报时会不会误转（要用日志回放）
- 错位检测能不能抓到（要注入故障）
