## 1 三个点的定义（沿行进方向，第一个弯的里程）

- **内拐点** = 内侧线拐弯处 = 拐角正方形近边，里程 **160**
- **C** = 中心线拐点 = 拐角正方形中心，里程 **180** ← **说「弯口」一律指 C**
- **外拐点** = 外侧线拐弯处，里程 **200**（`Doc/赛道数据.md` 原来量的是这个）

关系：外拐点比 C 靠前 `20 × tan(θ/2)`，20 = 外线到中心线的横向距离（半个车道宽）。

---

## 2 两个公式（都来自同一个 tan(θ/2)）

- **窗口宽度** = `20 × tan(θ/2)`
  90° → 20.0　103° → 25.1　38.5° → 7.0（厘米）
- **最理想开转点** = C 之前 `R × tan(θ/2)`，R = 转弯半径
  R 理论 7.2 厘米（左 26.55 档 / 右 3.45 档 → 转率 337°/秒，中心 42.1 厘米/秒）
  R 实测折算 10.0 厘米（1730 计数转 90° → 240°/秒）
  取中值 8.5 → 90° 弯要提前 **8.5 厘米**开始转

- 内拐点跑到前方 27.7 厘米时（车在里程 132.3），该行开始坏

## 8 遥测（蓝牙发出去的那 7 个通道）

`TELEMETRY_MODE` 四选一：

- **0 跑车（默认）**：轮目标/实际 ×4 ＋ 视觉偏差 ＋ 报弯里程 ＋ 开转里程
- 1 视觉台架：状态 / 偏差 / 实时段内里程 / 报弯里程 / 开转里程 / 收到帧数 / 连丢次数
- 2 里程台架：左右轮累计计数 / 实时段内里程 / 累计换算厘米（和卷尺比）/ 两个锁存里程
- 3 陀螺仪台架：WHO_AM_I / X / Y / Z 原始读数 / 累计角度

**通道 5 = 报弯里程（锁存），通道 6 = 开转里程（锁存）**，都在事件瞬间存下，不是采样。
