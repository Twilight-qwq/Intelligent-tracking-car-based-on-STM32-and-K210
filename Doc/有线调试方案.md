# 有线调试方案（不拔卡）

> 目的：改参数、看输出都在 USB 线上完成，不再拔卡。
> 适用：K210 / MaixPy，USB 串口 115200。

---

## 一、板子的两种跑法

| 跑法 | 谁在跑 | 输出去哪 |
|---|---|---|
| 插 USB，上电自动跑卡上的 `main.py` | 板子自己 | USB 串口（能被电脑抓） |
| MaixPy IDE 里点「运行」 | IDE 灌进去临时跑 | IDE 下面的终端 |

**我们要用的是第一种**：板子上电就跑，程序输出从 USB 串口出来，电脑能抓。

---

## 二、改参数不拔卡

用 MaixPy IDE：

1. 打开 IDE → 选开发板（Maix Bit）→ **连接**
2. 打开电脑上的 `live_scan_test.py`
3. 工具菜单 → **保存打开的脚本到开发板**（文件名 `main.py`）
4. 拔插一次 USB（或按复位）→ 板子就会跑新版本

> 关键：改的是**板子上的文件**，不是电脑上的。电脑上那份也要同步改，不然下次会覆盖回去。

---

## 三、看输出不拔卡

### 方式 A：MaixPy IDE 里看（你操作）

连接状态下，IDE 下面那块终端会直接显示 `print` 的内容。

### 方式 B：脚本抓串口（我操作）

`E:\WorkingPlace_DS\_serial\capture.ps1`

```
capture.ps1                    列出本机串口
capture.ps1 -Port COM5         抓 60 秒，存到 _field_shots\serial_时间.txt
capture.ps1 -Port COM5 -Seconds 120
```

> **硬性条件：抓的时候 MaixPy IDE 必须断开**。同一个串口只能一个人占。

---

## 四、一个完整循环（约 3 分钟）

1. 板子插 USB（不用拔卡）
2. **我**：列串口 → 抓 60 秒 → 从输出里抽 9 个「实」半宽 → 算新参数
3. **我**：告诉你改哪两行、改成什么
4. **你**：IDE 里改那两行 → 保存到开发板
5. 拔插 USB 重启 → 回到 2

标定阶段每轮只要改 2 个数；调阈值阶段每轮改 1 个数。

## 五、分工

| 事 | 谁 |
|---|---|
| 列串口、抓日志、抽数、算参数、算里程、看日志找问题 | **我** |
| 在 IDE 里改那两行、点保存 | 你（或我用串口改，见下） |
| 插线、摆车、扶车、按复位 | 你 |
| 判断「这圈跑得行不行」 | 一起看 |

### 我能再往前一步（有风险）

我可以通过串口 REPL 直接给板子发命令：中断当前程序 → 重写 `/sd/main.py` 里那两行 → 软重启。
这样就完全不用你动手。

**但要先试通，而且失败的话板子会停在 REPL 不动**，那时得拔卡或重烧恢复。
所以：**先用方式 B 抓一轮，确认串口能通**，再决定要不要让我直接改。

---

## 六、已知前提

- 卡上必须有 `main.py`，否则板子上电进 REPL，不跑程序
- 波特率 115200，8N1
- 板子的 USB 串口一般是 CH340（设备管理器里叫「USB-SERIAL CH340」）
- 电脑现在有 COM3 / COM4 / COM5 / COM15 四个口，**插上板子前后对比一次**才知道哪个是它

---

## 七、抓不到怎么办

1. 确认 IDE 已断开（不是最小化，是点「断开连接」）
2. 确认端口号对（拔插一次对比列表）
3. 确认卡上有 `main.py`（有的话程序一上电就打印）
4. 都不行 → 退回老办法：拔卡，读 `run_log.txt`
