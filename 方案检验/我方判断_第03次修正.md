## 1. 我方认错（重大）：我读错了它的方案

### 1.1 事实

**它的原文**（`wb_ai第3次修正` §二C「§9.1 数第几个弯」那一行，以及原报告 §五.1）：

> 首选：编码器里程查表（上表）。硬信号……**只需在出弯时清零里程并记住上一个弯的类型**。
> 备份：**视觉状态 2 触发**。保留原触发做兜底，但「用哪个角度」由里程表决定，不由视觉决定。

**我第 02 次修正 §4.1 写的是**：

> 它的方案：视觉报状态 2 → 里程查表决定「该转多少度」→ 转

**这是我读错了。** 它把里程当**主触发**，视觉只是兜底。我把它写反了。

### 1.2 后果

- 我第 02 次修正里的「核心分歧」（§4.1~§4.4）**不成立**，撤回。
- 我提的「折中建议」（里程为主 + 视觉校验）**就是它已经写的东西**，等于我在给一个不存在的问题开药方。

### 1.3 为什么错

它的 §五.1 标题是「首选 / 备份」，我扫成了「触发 / 选角度」两条不同的东西。
**教训：引用别人的方案，要把原文原句抄下来，再下判断。**

### 1.4 立场本身不变

我坚持的是「**视觉不报弯时，里程也要照转**」。
它 §五.4 的架构图 `巡线 → 里程达阈值 → 预备转弯` 正是这个意思。

**所以这一点上我们本来就一致，是我没读懂。**

## 3. 我反对它的三条

### 3.1 反对：它说我的坐标 `124.5 / 249` 和 294 对不上

它的原话：「它的坐标点 124.5 / 249 与材料『底边 294 cm』对不上（294 一半是 147）」。

**它漏看了我第 01 次修正 §3.1 的推导**，那里写得很清楚：

```
两条斜边水平投影 = 2 × 200 × sin38.5° = 249.0   ← 车道【中心线】的底边长
车道中心线到外侧黑线内边缘 = 半车道 20 + 半线宽 2.5 = 22.5
外侧内边缘之间 = 249.0 + 2 × 22.5 = 294.0       ← 用户量的就是这个
```

**249 和 294 是两个不同的参考系，差 45 cm = 2 × 22.5 cm。** 坐标没错，是它把两个参考系当成同一个了。

### 3.2 反对：它说「查钝角弯报不报状态 2」做不到

它说「标签是假的 → 分不出哪段是钝角弯 → 做不到」。

**标签是假的这一点我认，但结论夸大了。** 至少还有两条可执行的办法，它都没提：

**(a) 按「新的一次运行」分段，数每圈的报弯次数**

日志里每次运行之间有 `########## 新的一次运行 ##########` 分隔。
一圈应该报 **5 次**。某次完整跑完的日志里只出现 **4 次** → 漏掉的那个就是钝角弯（因为钝角最浅，最容易被漏）。

这不需要标签，只需要「这次运行跑完整整一圈」这个前提。

**(b) 用报弯之间的里程间隔反推**

相邻两次报弯之间的里程，应该是 110 / 200 / 200 / 110 / 294 这几个数里的。
如果某次运行里出现了「200 之后直接 110」这种跳变，中间缺的那个 200 就对应漏掉的弯。

**两条都不用车、不用摄像头、不用改代码，只要有日志。**

### 3.3 反对：它的理由 (a) 不成立

它 §3.3.1 说：「钝角弯恰恰是视觉不报——此时『以视觉为准』没有信号可用」。

**这是把两个分支混在一起批。**

我的规则原文是「**视觉报弯时**，检查里程读数；读数离阈值很远 → 以视觉为准」。
视觉不报的时候，走的是另一条分支「里程照转，不等待视觉」。

**它批的那条路，在『视觉不报』这个情形下根本不会被执行。**

（但它的理由 (b) 成立，所以规则还是要改保守。见 §5.2。）

## 5. 我方新增

### 5.1 打滑的方向：里程会读多，车会转早

编码器数的是**轮子转了多少**，不是**车走了多远**。

驱动轮打滑时：轮子转得多、地走得少 → **里程读数偏大** → 阈值提前到达 → **车在弯口之前就开始转**。

**这和实测的「提前转弯」是同一个方向。**

所以纯里程方案有个**系统性的偏早**。修正办法：

- 按实测校准阈值（不要用 110/200/294 的理论值直接写死）
- 或者故意放大 5%~10%，让车偏晚一点（晚一点比早一点好救）

### 5.2 修订后的冲突规则（四条）

| 情形 | 处理 |
|---|---|
| 里程到阈值（视觉报不报都一样） | **照转**，里程清零 |
| 视觉报弯，里程差 ≤ 10 cm | 转，里程清零（两边一致，最可信） |
| 视觉报弯，里程差 > 30 cm | **默认反光误报，不转、不清零** |
| 视觉连续 3 帧报弯、图案是真的弯（近 3 行全丢且只剩一条线）、且里程差在 10~30 cm | 允许把里程基准前移**一半**，不整个重置 |

核心：**里程是硬信号，视觉是软信号。视觉只能用来「发现漂移」，不能用来「改写基准」。**
